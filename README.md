# Control Vehicular — Grupo Metelmex

App web de control de flota (panel, unidades, combustible, casetas y prorrateo por centro de costo).

- Se publica con GitHub Pages desde la rama `main`.
- Versión actual: cascarón visual, sin datos. El formato de carga de información está pendiente.
- Nunca subir aquí: estados de cuenta de combustible, cruces de TAG, números de tarjeta, Excel con datos, código de Apps Script, claves ni respaldos (ver `.gitignore`).
